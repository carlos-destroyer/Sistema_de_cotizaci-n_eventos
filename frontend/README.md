# Frontend · M&M Eventos

Aplicación Next.js 16 (App Router) del sistema de cotizaciones.

## Comandos

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
npm run lint
```

La API se configura con `NEXT_PUBLIC_API_URL` (por defecto `http://localhost:8081/api`).

La documentación completa, instalación y scripts están en el [README principal](../README.md) y en [INIT.md](../INIT.md).
